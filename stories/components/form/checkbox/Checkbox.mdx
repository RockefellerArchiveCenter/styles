# Checkbox

A checkbox is an input control that allows a user to select one or more options
from a number of choices.

## When to use

Use a checkbox when you need to help users:
- Select multiple options from a list
- Toggle a single option on or off

Do not use a checkbox if users can only choose one option from a list. In this
case, use radio buttons.

## Best practices

- Checkboxes must have a clear and concise label.
- A group of checkboxes must have an associated legend.
- Users should be warned if selecting a checkbox will cause a change in context.
- If a single checkbox input is a required field include the `required` or `aria-required` property,
  indicate that it is a required field, and use a validation message for input errors.

## Grouping checkboxes

Related checkboxes should be grouped together using a `fieldset`
with a `legend` that describes the group of inputs. There is no standard programmatic
way to indicate that at least one checkbox is required to be selected in a fieldset. 
This should be handled by including the "*" character as part of the legend and, if necessary,
add form validation and associated error messages to enforce the requirement.
